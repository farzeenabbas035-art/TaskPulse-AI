# 📖 Project Overview

TaskPulse AI is an AI-powered productivity web application designed to help students, freelancers, and professionals manage their daily tasks, organize projects, and improve productivity.

Many people struggle to keep track of assignments, deadlines, and project progress across multiple platforms. TaskPulse AI solves this problem by providing a centralized workspace with AI-powered assistance that helps users organize work more efficiently.

This project was designed and developed as an original end-to-end application for the **Final Project – Ship Your AI App**.

---

# 🎯 Problem Statement

Managing multiple tasks, assignments, and projects can become overwhelming.

Users often face problems such as:

- Missing deadlines
- Poor task organization
- Lack of productivity
- Difficulty prioritizing work
- Switching between multiple productivity tools

TaskPulse AI addresses these challenges by combining project management with AI-powered assistance in a single application.

# 🤖 AI Feature

The application includes an AI assistant that helps users organize their work more effectively.

The AI can:

- Suggest task priorities
- Generate productivity recommendations
- Organize project workflows
- Improve planning based on user input

## AI System Prompt

The AI assistant is instructed to act as a productivity and project management assistant.

Example instruction:

> "You are an intelligent productivity assistant. Analyze the user's tasks and goals, recommend priorities, suggest improvements, organize projects into actionable steps, and provide concise, practical productivity advice."

# ⚙ Installation

## Prerequisites

- Node.js
- npm

## Clone Repository

```bash
git clone https://github.com/farzeenabbas035-art/TaskPulse-AI.git
```

## Navigate to Project

```bash
cd TaskPulse-AI
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env.local` file and add:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

## Run Development Server

```bash
npm run dev
```

# 🏗 Application Workflow

1. User enters tasks or project details.
2. The application sends the request to the Gemini API.
3. AI analyzes the input and generates recommendations.
4. The results are displayed in a clean, responsive interface.
5. Users can organize and export their work efficiently.
